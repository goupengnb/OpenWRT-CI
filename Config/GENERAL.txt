#---------- DNS（只留 AdGuard Home）----------
#dnsmasq-full：带 DNSSEC / nftset 的完整版，替换官方默认的精简 dnsmasq。
#它不是"另一个 DNS 软件"，而是系统的基础解析 + DHCP 服务，
#AdGuard Home 要挂它的 53 端口做上游，HomeProxy 的分流也要用它，所以必须留着。
CONFIG_PACKAGE_dnsmasq-full=y
# CONFIG_PACKAGE_dnsmasq is not set
#AdGuard Home：官方 packages 源的广告过滤面板 + 官方 luci 面板（唯一的 DNS 过滤组件）
CONFIG_PACKAGE_adguardhome=y
CONFIG_PACKAGE_luci-app-adguardhome=y
#按需求去掉了 SmartDNS 和 https-dns-proxy：多个 DNS 组件抢 53 端口会互相打架，
#只留 AdGuard Home 一个，配置反而清楚。

#---------- 网络服务（只留 ddns-go）----------

#它的 Makefile 已经声明了 sing-box / firewall4 / kmod-nft-tproxy / ucode-mod-digest，会自动带进来。
